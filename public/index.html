Help Center

How do I start a conversation?
Simply type your message in the chat input box and press enter or click the send button.
Can I copy the bot's responses?
Yes, click the copy button below any bot message to copy its content to your clipboard.
How can I edit images using a link?
You can easily edit or transform any image using the !nanoedit command.

Usage:
!nanoedit <image_link> | <prompt>

Example:
!nanoedit https://example.com/photo.jpg | turn this person into a cartoon superhero

➤ The bot will automatically process the image using Nano Banana AI and send back the edited image.

💡 Tip: Make sure your image link is public and ends with .jpg, .png, or .jpeg.
